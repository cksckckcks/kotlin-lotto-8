# kotlin-lotto-precourse

---

### 구현해야될 기능
- 로또 구입 금액을 입력받고 파싱, 검증하는 기능
  - 구매 금액이 1000원 단위가 아니면 Exception
  - 구메 금액이 1000원보다 작으면 Exception
- 당첨 번호를 입력받고 파싱, 검증하는 기능
  - 당첨 번호가 6자리가 아니라면 Exception
  - 당첨 번호에 중복이 있으면 Exception
  - 당첨 번호의 범위가 1~45 이내가 아니라면 Exception
  - 당첨 번호에 숫자가 아닌 값이 있으면 Exception
- 보너스 번호를 입력받고 파싱, 검증하는 기능
  - 보너스 번호가 1개가 아니라면 Exception
  - 보너스 번호가 1~45 이내가 아니라면 Exception
  - 보너스 번호가 당첨 번호와 중복된다면 Exception
- 잘못된 값 입력 시 Exception 발생시키고 에러메시지 출력 후 그 부분부터 다시 입력받는 기능
- 구매 금액만큼 로또를 발행하고 오름차순 정렬 후 출력하는 기능
- 당첨 내역을 출력하는 기능
  - 당첨 통계를 확인하는 기능
- 수익률을 출력하는 기능
  - 수익률을 계산하는 기능
